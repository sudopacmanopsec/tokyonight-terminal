  tmux cheat sheet      prefix = Ctrl+A      (press prefix, let go, then the key)
  Ctrl+A Ctrl+A sends a literal Ctrl+A to the program (e.g. shell "go to line start")

== Basics ==
  prefix r              reload ~/.config/tmux/tmux.conf
  prefix ?              list every key binding (q to close)
  prefix d              detach (session keeps running)
  prefix :              tmux command prompt
  Ctrl+d                close the current shell / pane

== Sessions ==
  tmux new -As main     attach to "main", or create it
  tmux ls               list sessions
  tmux attach -t name   attach to a session by name
  prefix s              session tree
  prefix $              rename session
  prefix ( or )         previous / next session

== Windows (tabs) ==
  prefix c              new window
  Alt+1 .. Alt+9        jump straight to window by number
  Shift+Left / Right    previous / next window
  prefix p / n          previous / next window
  prefix w              window list
  prefix ,              rename window
  prefix &              kill window

== Panes ==
  prefix |              split side by side (same directory)
  prefix -              split top / bottom (same directory)
  prefix h j k l        move to the pane left / down / up / right
  Alt+h j k l           same, without the prefix
  prefix z              zoom the current pane (again to undo)
  prefix x              kill pane
  prefix { or }         swap pane with previous / next
  prefix Ctrl+arrows    resize the pane (hold Ctrl, tap arrows)

== Copy mode (vi keys) ==
  prefix [              enter copy mode
  v                     begin selection
  Ctrl+v                rectangle selection on/off
  y                     copy selection and leave copy mode
  q                     leave copy mode without copying
  prefix ]              paste

== fzf pickers (popups) ==
  prefix f              fuzzy-switch session
  prefix t              fuzzy-pick window/tab
  prefix g              open a project as its own session
  (project roots: TMUX_FZF_ROOTS="$HOME/code:$HOME/work", default ~/projects ~/dotfiles ~/.config)
